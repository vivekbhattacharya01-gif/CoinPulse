# 📈 CoinPulse — Real-Time Cryptocurrency Tracker

A modern, responsive **cryptocurrency tracking platform** that displays live market prices of popular coins.
Built with **HTML, CSS, and JavaScript** using the [CoinGecko API](https://www.coingecko.com/).

🌐 **Live Demo:** [View on GitHub Pages](https://vivekbhattacharya01-gif.github.io/CoinPulse/)

![CoinPulse Preview](https://github.com/vivekbhattacharya01-gif/CoinPulse/blob/main/CoinPulse%20GIF.gif?raw=true)

---

## ✨ Features

- 📊 **Live Price Updates** — real-time data for Bitcoin, Ethereum, Litecoin, Ripple & Dogecoin
- 📈 **Daily % Changes** — profit & loss tracking at a glance
- 💻 **Responsive Design** — optimized for desktop, tablet, and mobile
- 🎨 **Modern UI/UX** — sleek dark theme, glassmorphism cards, hover effects
- 🌐 **Navigation Bar** — Market, Features, Whitepaper, Services & Contact
- ⚡ **20% faster load** — optimized rendering techniques

## ⚡ Getting Started

```bash
# Clone the repository
git clone https://github.com/vivekbhattacharya01-gif/CoinPulse.git

# Go to project folder
cd CoinPulse

# Open in browser
open index.html
```

> No build tools or dependencies needed — pure HTML, CSS & JS!

---

## 📡 API Reference

This project uses the **CoinGecko API** (free, no key required):

```
https://api.coingecko.com/api/v3/simple/price?ids=bitcoin,ethereum,litecoin,ripple,dogecoin&vs_currencies=usd
```
